# 📊 Excel Data Cleaning & Analysis Project

## 📌 Project Overview

This project focuses primarily on **data cleaning and preparation in Microsoft Excel**, with an emphasis on identifying and handling common data-quality issues before analysis.

The main goal was to transform raw and inconsistent data into a cleaner, more reliable dataset that can be used for accurate analysis and reporting.

## 🧹 Data Cleaning Focus

The project focused on the **six major data-cleaning checks**:

### 1. Missing Values
Identifying missing or blank values and handling them appropriately depending on the column and business context.

### 2. Errors
Detecting and fixing Excel/data errors to ensure the dataset is consistent and ready for analysis.

### 3. Duplicates
Checking for duplicate records and removing or handling them when necessary.

### 4. Validate
Using data validation to make sure entered values follow the required rules and formats.

### 5. Detected Type
Checking the detected data type of columns and correcting incorrect types when needed, especially for dates, numbers, and text.

### 6. Outliers — IQR Method
Detecting unusual values using the **Interquartile Range (IQR)** method.

The IQR is calculated as:

**IQR = Q3 − Q1**

Outlier boundaries:

- **Lower Bound = Q1 − 1.5 × IQR**
- **Upper Bound = Q3 + 1.5 × IQR**

Values outside these boundaries were investigated as potential outliers.
